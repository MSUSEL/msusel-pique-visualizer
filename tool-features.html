Tool Features of the PIQUE Visualizer

The PIQUE Visualizer is equipped with a range of features designed to provide a comprehensive understanding of software quality assessments. This page highlights the key features of the tool, enabling users to fully leverage its capabilities for their quality analysis needs.

Hierarchical Tree Visualization​

  • Overview: Central to the PIQUE Visualizer is its ability to display complex quality assessment data in a hierarchical tree format. This visualization simplifies the interpretation of how different factors, measures, and diagnostics contribute to the overall quality score.
  • Interactive Elements: Users can interact with the tree to expand and collapse nodes, revealing the intricate details of each component's contribution to the software's quality.

Dynamic Weight Adjustment​

  • Purpose: Understanding the impact of various quality factors is crucial. The PIQUE Visualizer allows users to dynamically adjust the weights of these factors, offering insights into how changes might affect the overall quality score.
  • Functionality: Through an intuitive interface, users can modify weights and immediately see the adjusted results in the visualization, facilitating a deeper analysis of quality determinants.

Detailed Information Panel​

  • Accessing Node Details: Clicking on a node within the tree presents a detailed information panel. This panel provides extensive data about the selected component, including descriptions, values, and impact scores.
  • Enhanced Understanding: This feature aids users in comprehensively understanding the specifics of each factor, measure, and diagnostic, contributing to informed decision-making.

File Upload and Processing​

  • Simplified Uploads: Users can easily upload the JSON file structured according to the PIQUE analysis results. The visualizer supports compact JSON formats for efficient processing.
  • Immediate Visualization: Upon upload, the tool processes the file and instantly presents the visualization, allowing for a quick start to quality assessment analysis.

Sorting and Filtering Capabilities​

  • Customized Views: To aid in focusing on specific areas of interest, the PIQUE Visualizer includes sorting and filtering functionalities. Users can sort nodes based on scores or weights and apply filters to hone in on particular score ranges or weight values.
  • Reset Function: A reset option is available to quickly revert back to the original view after applying various sorts and filters, ensuring flexibility in analysis.

User-Friendly Interface​

  • Ease of Use: The PIQUE Visualizer is designed with a user-friendly interface, making it accessible for users of all technical levels. Clear instructions and intuitive controls ensure a seamless experience.
  • Quick Actions: For common tasks like removing nodes with zero weights or adjusting the view, quick action buttons are provided, streamlining the analysis process.

Conclusion​

With these features, the PIQUE Visualizer stands out as a powerful tool for visualizing and analyzing software quality. Whether for detailed research, quality assurance processes, or educational purposes, the visualizer provides valuable insights into the factors influencing software quality.
